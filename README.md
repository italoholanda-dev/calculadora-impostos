Um sistema web interativo para comparar a rentabilidade e os descontos tributários entre o regime de contratação CLT e a prestação de serviços como Pessoa Jurídica (PJ). 

Este projeto foi desenvolvido para resolver um problema comum e prático do mercado de trabalho: auxiliar profissionais a tomarem decisões financeiras mais embasadas ao analisar propostas de emprego, transições de carreira ou ao gerenciar contratos de prestação de serviço e registros empresariais.

## ✨ Funcionalidades

- **Alternância de Modos de Cálculo:** Navegação fluida entre as abas de cálculo exclusivo para CLT ou PJ (Simples Nacional e Lucro Presumido).
- **Entrada de Dados Intuitiva:** Campos claros para inserção de Salário Bruto Mensal, Faturamento e Número de Dependentes.
- **Cálculo de Encargos Trabalhistas e Tributários:** Simulação automática de FGTS, INSS progressivo, IRRF e alíquotas PJ.
- **Interface Limpa e Responsiva:** Design minimalista e profissional, focado na usabilidade e na clareza das informações financeiras.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando os fundamentos do Desenvolvimento Web, sem a dependência de frameworks externos:

- **HTML5:** Estruturação semântica do conteúdo e dos formulários.
- **CSS3:** Estilização visual (cores, espaçamentos, tipografia) e layout responsivo.
- **JavaScript (Vanilla):** Lógica de cálculo dos impostos, manipulação do DOM e alternância dinâmica das abas da interface.

## 🚀 Como Executar o Projeto Localmente

1. Clone este repositório para a sua máquina:
   ```bash
   git clone https://github.com/italoholanda-dev/calculadora-impostos.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd calculadora-impostos
   ```
3. Abra o arquivo `index.html` em seu navegador de preferência. Não é necessária nenhuma instalação adicional.
